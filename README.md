# 🎯 Guessly

**Guess. Think. Win.**

Guessly is an interactive guessing game web application where users can test their knowledge, answer questions, and enjoy a simple and engaging gaming experience.

## 🌐 Live Demo

👉 **[Try Guessly Live](https://guessly-three.vercel.app)**

## ✨ Features

* User authentication
* Interactive guessing game
* Responsive design
* Clean and simple user interface
* Game feedback and results
* Protected user pages

## 🛠️ Built With

* React.js
* JavaScript
* Vite
* React Router
* CSS
* REST API Integration

## 🚀 Getting Started

### Installation

```bash
npm install
```

### Run the project

```bash
npm run dev
```

## 📱 Responsive Design

Guessly is designed to work across:

* Desktop
* Tablet
* Mobile
